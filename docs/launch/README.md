# Launch kit

Everything needed to publish Foremon 1.0.0 and tell people about it. Each file has text ready to paste.

None of the accounts below were signed in on this computer's browser, and signing up or signing in
needs a password and verification only you can do. Once you are signed in, I can do the uploading
and posting for you.

## Order

| # | What | File | Needs from you |
|---|---|---|---|
| 1 | An email address just for the mod | [email.md](email.md) | Create it (password, phone check) |
| 2 | GitHub repository: code and bug reports | [github.md](github.md) | Sign in to GitHub in the Claude browser, then I push |
| 3 | Modrinth page and the 1.0.0 file | [modrinth.md](modrinth.md) | Sign in to Modrinth in the Claude browser |
| 4 | CurseForge page and the 1.0.0 file | [curseforge.md](curseforge.md) | Sign in to CurseForge in the Claude browser |

| 7 | Post on r/Cobblemon (and r/feedthebeast) | [posts.md](posts.md) | Post it (the Claude browser cannot open Reddit) |
| 8 | TikTok and YouTube Shorts | [tiktok.md](tiktok.md) | Create the account, upload the video |

## Files for the pages

- Mod jar: `build/libs/foremon-1.0.0.jar` (also in your COBBLEVERSE mods folder)
- Icon: `src/main/resources/assets/foremon/icon.png` (128x128) and `docs/media/icon-512.png`
- GIFs: `docs/media/timber.gif` (a whole tree in one swing) and `docs/media/build.gif` (a Litematica house)
- TikTok video: `docs/media/foremon-tiktok.mp4` (vertical, 1080x1920)
- Screenshots: `docs/media/screenshot-*.png`
- Description: [../MODPAGE.md](../MODPAGE.md). Changelog: [../../CHANGELOG.md](../../CHANGELOG.md)

## Things to say everywhere

- It is **v1**: ask people to report bugs on GitHub issues.
- It was **developed with an AI coding assistant**. Disclose it on every page and post. Where the site has an AI
  toggle (Modrinth's "Contains AI-generated content", TikTok's "AI-generated content" switch in the upload form),
  use the toggle and leave it out of the text. Where there is none (CurseForge, GitHub, Reddit, Beacons), say it in the text.
- Stamina and food can be switched off in the settings, for players who dislike upkeep.
- Requirements: Minecraft 1.21.1, Fabric, Fabric API, Fabric Language Kotlin, Cobblemon 1.7.3 or newer.
  Litematica is optional.
