# Your own Discord server

Name: **Foremon**. Icon: `docs/media/icon-512.png`.

## Channels

**Info**
- `#welcome`: what the mod is, links, rules (text below)
- `#announcements`: releases and news (only you can post)
- `#changelog`: each version's changelog (only you can post)

**Community**
- `#general`
- `#showcase`: screenshots and videos of your workers and builds
- `#schematics`: share Litematica builds your crews can build

**Feedback**
- `#bug-reports` (a forum channel, one post per bug; ask for Minecraft, Cobblemon and Foremon versions and the log)
- `#ideas` (a forum channel, people vote with reactions)
- `#roadmap`: the roadmap image, updated as things land

**Help**
- `#help`: questions about playing
- `#server-owners`: settings, permissions, performance

## Roles

- `Dev`: you
- `Tester`: people who report bugs (give it as thanks)
- `Server owner`: people running Foremon on a server
